## Start here: SQL Atlas

[SQL Atlas](https://github.com/milekv/sql-atlas) is a local SQL analyzer for the browser, VS Code, the terminal and pull requests. It marks findings in source code, suggests index candidates and imports PostgreSQL, SQL Server and Oracle execution plans for inspection. The same analyzer core powers the editor, CLI and GitHub Action.

[Try the live app](https://milekv.github.io/sql-atlas/) · [Read the docs](https://github.com/milekv/sql-atlas#readme) · [Polska dokumentacja](https://github.com/milekv/sql-atlas/blob/main/README.pl.md)

The browser demo follows the current source; published npm, VS Code and Action releases have separate version cycles. SQL Atlas performs static analysis and plan review. It does not run your queries or claim that a suggested rewrite is faster without measurement.
